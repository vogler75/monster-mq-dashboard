Broker Scripts Reference

The Broker Script Engine executes fast, standalone scripts directly inside the MonsterMQ broker process. Unlike legacy FlowEngine visual workflows, scripts are defined as standalone entities with straightforward syntax and zero diagram overhead.

Cross-Platform Parity: Scripts written in Python/Starlark run seamlessly on both MonsterMQ Main (JVM GraalPy) and MonsterMQ Edge (pure-Go Starlark) with identical API bindings.

Runtime Support

Language Engine Supported Platforms Description
python GraalVM Polyglot Python (GraalPy) MonsterMQ Main Broker Full Python 3.11+ compliant Truffle runtime running on OpenJDK. Fast JIT compilation with standard library math, json, re, etc.
starlark Google Starlark MonsterMQ Edge & Main Deterministic, lightweight Python dialect implemented in pure Go. Extremely safe, hermetic, and instant startup for IoT edge nodes.
javascript GraalVM JavaScript (GraalJS) MonsterMQ Main Broker Modern ECMAScript (ES2022) runtime with full standard object model.

Execution Model & Triggers

Scripts can be triggered through one or more mechanisms:

  • TOPIC: Executes whenever a message matching configured MQTT topic filter(s) arrives. If Trigger on Change Only is enabled, execution skips duplicate consecutive payloads.
  • TIMER: Executes periodically at a fixed millisecond interval (e.g. 5000 ms). On timer ticks, msg is None / null.
  • BOTH: Responds to incoming MQTT messages as well as periodic timer intervals.
  • CALLABLE: Executes only when explicitly invoked by another script via scripts.call(name, args) or via the test sandbox.

Concurrency Modes

SINGLETON (Default): All executions for a given script instance run serially in a dedicated queue, guaranteeing that in-memory state remains free of race conditions.

MULTI_INSTANCE: Invocations execute concurrently across the broker worker pool for high-throughput, stateless workloads.

1. msg (Incoming Message)

Available on topic triggers. None (or null) during timer ticks.

# Python / Starlark
if msg is not None:
    topic = msg["topic"]             # e.g. "sensors/chiller/temp"
    payload = msg["payload"]         # parsed JSON dict/list or string
    raw = msg["raw_payload"]         # raw string payload
    qos = msg["qos"]                 # 0, 1, or 2
    retain = msg["retain"]           # boolean
    ts = msg["timestamp"]            # ISO 8601 string

2. mqtt (Broker MQTT Operations)

Publish messages into the broker or subscribe dynamically:

# Publish
mqtt.publish("alerts/temperature", json.encode({"alarm": True, "value": 85.4}), qos=1, retain=True)

# Subscribe (callback function)
def on_sub_msg(sub_msg):
    log.info("Received sub message on: " + sub_msg["topic"])

mqtt.subscribe("cmd/reset/+", on_sub_msg)

3. archive (Historical & Last-Value Queries)

# Get latest recorded message for a topic
last_val = archive.get_last_value("sensors/ambient/temperature", archive_group="Default")
if last_val is not None:
    log.info("Previous value was: " + str(last_val["payload"]))

# Get historical messages
records = archive.get_history("sensors/ambient/temperature", limit=50)

4. db (Database Connections)

Execute queries on configured database connections or SQLite/Postgres stores:

# Query returns a list of dictionaries / objects
rows = db.query("PostgresStore", "SELECT status, setpoint FROM equipment WHERE id = $1", [42])
for row in rows:
    log.info("Setpoint: " + str(row["setpoint"]))

# Execute UPDATE / INSERT
res = db.execute("PostgresStore", "UPDATE equipment SET last_seen = NOW() WHERE id = $1", [42])

5. Scoped Memory (state & global)

  • state: Mutable in-memory dict preserved across invocations for this script instance. Perfect for moving averages, counters, or state machines.
  • global (or globals): Shared across all scripts on the current broker node. Methods: global.get(key), global.set(key, val).
# Retain counter in local state
state["count"] = state.get("count", 0) + 1

# Node-wide shared variable
global.set("active_shift", "Shift-A")

6. storage (Persistent KV Store)

Persists key-value data to disk surviving broker restarts and script reloads:

# Get value with default
max_limit = storage.get("max_temp_limit", 100.0)

# Set persistent value
storage.set("last_reboot_cycle", 5)

# Delete key
storage.delete("temporary_flag")

7. scripts.call (Inter-Script Calls)

Invoke another script registered with trigger type CALLABLE:

result = scripts.call("CalculateEfficiency", {"flow": 12.5, "pressure": 4.2})
log.info("Efficiency result: " + str(result))

Recipe: Threshold Alert & Retained Alarm

# Trigger: TOPIC (sensors/+/temp)
if msg != None and isinstance(msg["payload"], dict):
    temp = msg["payload"].get("temperature", 0)
    dev_id = msg["topic"].split("/")[1]
    
    if temp > 75.0:
        alarm_msg = {
            "device": dev_id,
            "temperature": temp,
            "status": "ALARM_HIGH",
            "time": msg["timestamp"]
        }
        mqtt.publish("alarms/" + dev_id, json.encode(alarm_msg), qos=1, retain=True)
        log.warn("High temperature on " + dev_id + ": " + str(temp))
    elif temp < 65.0:
        # Clear alarm
        mqtt.publish("alarms/" + dev_id, json.encode({"device": dev_id, "status": "OK"}), qos=1, retain=True)

Recipe: Moving Average Filter

# Trigger: TOPIC (meters/power)
if msg != None:
    val = float(msg["raw_payload"])
    history = state.get("window", [])
    history.append(val)
    if len(history) > 10:
        history.pop(0)
    state["window"] = history
    
    avg_val = sum(history) / len(history)
    mqtt.publish("meters/power/smoothed", str(round(avg_val, 2)), retain=True)

Recipe: Database Query on Periodic Timer

# Trigger: TIMER (Interval: 10000 ms)
rows = db.query("PostgresStore", "SELECT tag_name, tag_value FROM plant_tags WHERE modified > NOW() - INTERVAL '10 seconds'", [])
for row in rows:
    topic = "plant/tags/" + row["tag_name"]
    mqtt.publish(topic, str(row["tag_value"]), qos=0, retain=True)
log.info("Synced " + str(len(rows)) + " tags from database")
